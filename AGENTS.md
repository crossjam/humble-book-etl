# Project conventions

## Squash-merge commit messages

Keep the subject concise, but give the commit body enough context:

1. Include the PR description's **Summary** section, retaining its substantive
   details rather than reducing it to a one-line summary.
2. List the branch's commits using each commit's short hash and title.
3. Include attribution naming the contributing agent(s) and verified model(s),
   including delegated implementation, testing, and review contributors.
   Do not guess model identities; explicitly note unavailable attribution.

Apply this convention to future squash merges. Do not rewrite already-merged
commits unless explicitly requested.
